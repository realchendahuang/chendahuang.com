Cloudflare تقریباً می‌تواند کل زیرساخت اینترنتیِ شخصیِ یک نفر را روی پا نگه دارد: دامنه، وب‌سایت، CDN، ذخیره‌سازی اشیاء، دیتابیس، توابع لبه (edge functions)، تونل، فوروارد ایمیل، CAPTCHA و یک گیت‌وی هوش مصنوعی — همهٔ این‌ها می‌توانند از لایهٔ رایگان شروع کنند.

## DNS رایگان

Cloudflare خودش ثبت‌کنندهٔ دامنه است و قیمت ثبت و تمدیدش نسبتاً شفاف است. همچنین می‌توانی دامنه را در پلتفرم‌هایی مثل Spaceship بگیری و DNS را به Cloudflare منتقل کنی.

وقتی دامنه‌ات وارد Cloudflare شد، یک سیستم مدیریت DNS محکم می‌گیری.

نکتهٔ کلیدی: رزولوشن DNS به‌ازای هر کوئری صورتحساب نمی‌شود. برخلاف بعضی غول‌های داخلی که آن‌قدر زشت هستند که حسابِ تعداد رزولوشن باز می‌کنند — از این بی‌حیایی بگو.

Cloudflare برای چند دامنه، چند زیردامنه و ماتریس پروژه‌های کوچک عالی است.

می‌توانی راه بیندازی:

- `api.xxx.com`
- `img.xxx.com`
- `cdn.xxx.com`
- `docs.xxx.com`
- `status.xxx.com`
- `admin.xxx.com`

یک دامنه بخر، زیردامنه‌های مختلف را به سرویس‌های مختلف اختصاص بده؛ خودِ رزولوشن DNS هزینهٔ اضافه‌ای ندارد.

برای ترافیک وب که نیاز به پروکسی دارد، ابر نارنجی را روشن کن و بگذار Cloudflare پروکسی، کش و گواهی HTTPS را مدیریت کند.

## CDN رایگان

کش CDN باحال‌ترین چیز Cloudflare است — بیشتر مردم از همین راه با شرکت آشنا می‌شوند. برای بلاگ‌ها، سایت‌های رسمی و سایت‌های مستندات، ارزشش مستقیم است:

بازدید سریع‌تر، سرور مبدأ سبک‌تر و پهنای باند کمتر. به‌خصوص اگر روی VPS ارزانی هستی، گذاشتن Cloudflare جلوترش، تفاوتی کاملاً محسوس ایجاد می‌کند.

## Pages رایگان

Pages می‌تواند سایت‌ها و پروژه‌های فرانت‌اند استاتیک را رایگان میزبانی کند.

- بلاگ شخصی
- وب‌سایت محصول
- سایت مستندات
- صفحهٔ فرود (landing page)
- صفحهٔ پروژهٔ متن‌باز
- صفحهٔ مطالب دوره
- صفحات لیست انتظار
- صفحهٔ راهنمای دانلود
- صفحات تبلیغی کتاب الکترونیکی

این‌ها را می‌توان مستقیم میزبانی کرد، بدون خرید سرور جداگانه. دامنهٔ خودت را وصل کن و تبدیل می‌شود به سایت شخصی یا صفحهٔ خانگیِ پروژه که تا مدت طولانی سر پا می‌ماند.

## Workers رایگان

وقتی سایتت به API، احراز هویت یا منطق داینامیک دیگر نیاز دارد، از Workers استفاده کن. کدت روی شبکهٔ Cloudflare اجرا می‌شود — بدون نیاز به نگهداری سرور از طرف تو. غیر از JavaScript / TypeScript، WebAssembly و سایر رانتیم‌ها هم پشتیبانی می‌شود.

لایهٔ رایگان روزانه ۱۰۰ هزار درخواست دارد. اگر پروژهٔ شخصی واقعاً از این مقدار عبور کرد، پلن پولی را بگیر — عجله نیست.

Workers Paid از ۵ دلار در ماه شروع می‌شود.

خیلی از پروژه‌های کوچک اصلاً به بک‌اند کامل نیاز ندارند. یک Worker کافی است.

## KV رایگان

KV برای داده‌هایی مناسب است که خواندن سریع می‌خواهند ولی سازگاری قوی لازم ندارند — پیکربندی، پرچم‌های ویژگی، نتایج کش. جایگزین کامل Redis نیست، اما خیلی از نیازهای سادهٔ پروژه‌های شخصی را پوشش می‌دهد.

## D1 رایگان

D1 دیتابیس SQLite مدیریت‌شدهٔ Cloudflare است، برای داده‌های رابطه‌ای خوب است. لایهٔ رایگان شامل ۵ گیگابایت ذخیره‌سازی کل، به‌علاوه سهمیهٔ روزانهٔ خواندن و نوشتن است.

## R2 رایگان

R2 ذخیره‌سازی اشیاء سازگار با API سرویس S3 است، برای تصاویر، فایل‌ها و بکاپ‌ها مناسب است. بزرگ‌ترین مزیتش: سرو کردن مستقیم از R2 هزینهٔ پهنای باند ندارد — بیشتر هزینه‌ات بابت ذخیره‌سازی و تعداد عملیات است. لایهٔ رایگان هم برای هر دو سهمیه دارد.

می‌توانی در آن بگذاری:

- تصاویر
- فایل‌های پیوست
- PDFها
- مطالب دوره
- بسته‌های نرم‌افزاری
- فایل‌های بکاپ
- آواتار کاربران
- تصاویر مارک‌داون
- منابع استاتیک
- دیتاست‌ها
- فایل‌های صوتی
- ویدئوهای کوچک

## Email Routing رایگان

Email Routing ایمیل‌های ارسالی به دامنهٔ سفارشی‌ات را به یک صندوق موجود فوروارد می‌کند — در لایهٔ رایگان در دسترس است. Cloudflare همچنین سرویس Email Sending برای ایمیل‌های تراکنشی از طریق Workers دارد، اما ارسال به گیرندگان دلخواه نیاز به Workers Paid دارد، پس آن را با فوروارد رایگانِ دریافت اشتباه نگیر.

## Turnstile رایگان

Turnstile تأییدِ انسان‌بودنِ Cloudflare است که معمولاً کاربر مجبور نیست چراغ راهنمایی یا حروف خمیده را تشخیص دهد. برای این جاها خوب است:

- ورود (login)
- ثبت‌نام
- کامنت
- فرم تماس
- لیست انتظار
- صفحه‌های دانلود
- اشتراک ایمیل

## Tunnel رایگان

می‌خواهی NAS خانه‌ات، ماشین توسعهٔ محلی یا سرور بازیت در معرض اینترنت باشد؟ با Tunnel یک لوله بساز که از شبکهٔ داخلی‌ات به سمت Cloudflare به‌صورت فعالانه وصل می‌شود.

NAS خانه‌ات، ماشین‌های توسعهٔ محلی و سرویس‌های داخلی‌ات — همه می‌توانند از طریق Cloudflare Tunnel در معرض دید قرار بگیرند. ارزش اصلی:

- بدون نیاز به IP عمومی
- بدون پورت‌فوروارد روی روتر
- بدون افشای IP مبدأ
- می‌توان دامنهٔ خودت را وصل کرد

مثلاً:

- `nas.xxx.com`
- `dev.xxx.com`
- `panel.xxx.com`
- `n8n.xxx.com`
- `home.xxx.com`

این چیز برای کسانی که سرور خانگی بازی می‌کنند یک نعمت است.

## Access رایگان

Access جلوی پنل‌های ادمین، محیط‌های استیجینگ و ابزارهای داخلی می‌ایستد و قبل از ورود، هویت را تأیید می‌کند. OTP ایمیلی، Google، GitHub یا تأمین‌کننده‌های هویت تیمی — همه کار می‌کنند؛ لازم نیست برای یک صفحهٔ داخلی یک سیستم ثبت‌نام/ورود دیگر بنویسی. مثلاً:

- فقط ایمیل‌های مشخص وارد می‌شوند
- فقط لاگین با Google وارد می‌شود
- فقط لاگین با GitHub وارد می‌شود
- فقط اعضای تیم وارد می‌شوند

برای محافظت از بک‌اندها، استیجینگ و ابزارهای داخلی خیلی به درد می‌خورد.

## AI Gateway رایگان

AI Gateway می‌تواند جلوی چند تأمین‌کنندهٔ مدل بایستد و درخواست‌ها، تأخیر، خطاها و کش‌هیت‌ها را یکجا ثبت کند، به‌علاوه محدودسازی نرخ (rate limiting) و برگشت (fallback). وقتی اوایل کارِ یک محصول هوش مصنوعی می‌سازی، مدیریت چند API سازگار از یک ورودی، کلی دردسر کم می‌کند.

با آن می‌توانی ببینی:

- حجم درخواست‌ها
- تأخیر (latency)
- خطاها
- کش هیت
- فراخوانی مدل‌ها
- محدودسازی نرخ
- fallback

چه با OpenAI کار کنی، چه Anthropic، چه Workers AI و چه APIهای سازگار مختلف، می‌توانی جلویشان یک لایه بگذاری.

برای محصولات اولیهٔ هوش مصنوعی، ورودی یکپارچهٔ خوبی می‌شود.

## Browser Run رایگان

Cloudflare حالا این قابلیت را Browser Run صدا می‌زند. نشست‌های کامل مرورگر را در کلود اجرا می‌کند که با کد یا هوش مصنوعی قابل کنترل است.

برای این‌ها خوب است:

- اسکرین‌شات صفحهٔ وب
- تبدیل صفحهٔ وب به مارک‌داون
- تست اتوماسیون وب
- جمع‌آوری محتوای صفحه
- تجزیهٔ صفحات داینامیک
- تبدیل صفحهٔ وب به PDF

یک سهمیهٔ رایگان روزانه دارد.

## Images Transform رایگان

Cloudflare Images سهمیهٔ تبدیل تصویر دارد برای تغییر اندازه، برش و تبدیل فرمت. مصرف سنگین جداگانه حساب می‌شود، یا در Workers پولی می‌توانی با Containers سرویس تبدیل خودت را اجرا کنی.

این را می‌شود با R2 ترکیب کرد:

- R2 نسخهٔ اصلی را نگه می‌دارد
- Images بندانگشتی (thumbnail) و تبدیل فرمت می‌سازد
- کش Cloudflare توزیع می‌کند

برای کاور بلاگ، آواتار، تصاویر محصول و تصویرسازی مقاله‌ها خوب است.

سهمیهٔ رایگان Cloudflare همین حالا کلی پروژهٔ شخصی را پوشش می‌دهد. اگر واقعاً به حجم درخواست بالاتر، زمان محاسباتی بیشتر یا قابلیت‌های پولی نیاز شد، از پلن Workers Paid با ۵ دلار در ماه شروع کن و بالا برو.

و اینجا می‌خواهم بگویم: Cloudflare، لطفاً پولت را واریز کن!!
