Cloudflare는 개인 인터넷 인프라 거의 전체를 지탱할 수 있다: 도메인, 웹사이트, CDN, 객체 스토리지, 데이터베이스, 엣지 함수, 터널링, 이메일 포워딩, CAPTCHA, AI 게이트웨이 — 전부 무료 플랜에서 시작할 수 있다.

## 무료 DNS

Cloudflare 자체가 도메인 등록 기관이며, 등록·갱신 가격이 꽤 투명하다. Spaceship 같은 플랫폼에서 도메인을 사서 DNS 호스팅을 Cloudflare로 옮길 수도 있다.

도메인을 Cloudflare에 연결하면, 탄탄한 DNS 관리 시스템을 바로 손에 넣는다.

핵심 포인트: DNS 리졸루션은 조회 건수로 과금되지 않는다. 국내 일부 대형 업체들처럼 조회 횟수로 요금을 매기는 것과는 다르다 — 파렴치하기 짝이 없다.

Cloudflare는 멀티 도메인, 멀티 서브도메인, 소규모 프로젝트 매트릭스에 아주 잘 맞는다.

이렇게 돌릴 수 있다:

- `api.xxx.com`
- `img.xxx.com`
- `cdn.xxx.com`
- `docs.xxx.com`
- `status.xxx.com`
- `admin.xxx.com`

도메인 하나 사면 서비스마다 다른 서브도메인을 배정할 수 있고, DNS 리졸루션 자체는 추가 비용이 없다.

프록시가 필요한 웹 트래픽은 오렌지 클라우드를 켜고 Cloudflare가 프록시, 캐싱, HTTPS 인증서를 맡게 하자.

## 무료 CDN

CDN 캐싱은 Cloudflare에서 가장 멋진 기능이다. 대부분의 사람이 Cloudflare를 이걸로 처음 알게 된다. 블로그, 공식 사이트, 문서 사이트에서는 가치가 명확하다:

방문이 더 빨라지고, 오리진 서버가 더 가벼워지고, 대역폭이 절약된다. 특히 값싼 VPS를 쓰고 있다면 앞에 Cloudflare를 붙이는 것만으로 체감이 크게 달라진다.

## 무료 Pages

Pages는 정적 사이트와 프런트엔드 프로젝트를 무료로 호스팅한다.

- 개인 블로그
- 제품 웹사이트
- 문서 사이트
- 랜딩 페이지
- 오픈소스 프로젝트 페이지
- 강의 자료 페이지
- 대기자 명단 페이지
- 다운로드 안내 페이지
- 전자책 홍보 페이지

이런 페이지는 별도 서버를 살 필요 없이 바로 호스팅할 수 있다. 내 도메인을 연결하면 장기적으로 유지할 개인 사이트나 프로젝트 홈페이지가 된다.

## 무료 Workers

사이트에 API, 인증, 기타 동적 로직이 필요하면 Workers를 쓰자. 코드는 Cloudflare 네트워크에서 실행되며, 내가 서버를 관리할 필요가 없다. JavaScript/TypeScript 외에 WebAssembly 같은 런타임도 지원한다.

무료 플랜에는 하루 10만 건의 요청 할당량이 포함된다. 개인 프로젝트가 정말로 그걸 넘어서면 유료로 올리면 된다. 서두를 필요 없다.

Workers Paid는 월 $5부터 시작한다.

많은 소규모 프로젝트는 완전한 백엔드가 아예 필요 없다. Worker 하나면 충분하다.

## 무료 KV

KV는 빠른 읽기는 필요하지만 강한 일관성은 요구하지 않는 데이터 — 설정, 기능 플래그, 캐시된 결과 — 에 맞다. 완전한 Redis 대체품은 아니지만, 개인 프로젝트의 단순한 요구를 상당 부분 커버한다.

## 무료 D1

D1은 Cloudflare가 관리하는 SQLite 데이터베이스로, 관계형 데이터에 적합하다. 무료 플랜에는 총 5GB 스토리지와 일별 읽기/쓰기 할당량이 포함된다.

## 무료 R2

R2는 S3 API 호환 객체 스토리지로, 이미지, 첨부 파일, 백업에 좋다. 가장 큰 장점은 R2에서 서빙할 때 대역폭 요금이 없다는 것 — 비용은 주로 스토리지와 작업 건수로 계산된다. 스토리지와 요청 모두 무료 플랜 할당량이 있다.

이런 걸 넣을 수 있다:

- 이미지
- 첨부 파일
- PDF
- 강의 자료
- 소프트웨어 패키지
- 백업 파일
- 사용자 아바타
- Markdown 이미지
- 정적 에셋
- 데이터셋
- 오디오 파일
- 짧은 비디오 에셋

## 무료 Email Routing

Email Routing은 내 커스텀 도메인으로 보낸 이메일을 기존 사서함으로 전달한다 — 무료 플랜에서 사용 가능하다. Cloudflare에는 Workers로 트랜잭션 이메일을 보내는 Email Sending도 있다. 하지만 임의 수신자에게 보내려면 Workers Paid가 필요하므로, 무료 수신 포워딩과 혼동하지 말자.

## 무료 Turnstile

Turnstile은 Cloudflare의 사람 인증이며, 사용자가 신호등이나 뒤틀린 글자를 판별해야 하는 경우가 대부분 없다. 다음과 같은 곳에 좋다:

- 로그인
- 회원가입
- 댓글
- 문의 폼
- 대기자 명단
- 다운로드 페이지
- 이메일 구독

## 무료 Tunnel

집에 있는 NAS, 로컬 개발 머신, 게임 서버를 외부에 노출하고 싶다면? Tunnel로 내부 네트워크에서 Cloudflare로 능동적으로 연결되는 파이프를 만들자.

집의 NAS, 로컬 개발 머신, 내부 서비스 — 전부 Cloudflare Tunnel로 노출할 수 있다. 핵심 가치:

- 공인 IP 불필요
- 라우터 포트 포워딩 불필요
- 오리진 IP 노출 없음
- 내 도메인 연결 가능

예를 들어:

- `nas.xxx.com`
- `dev.xxx.com`
- `panel.xxx.com`
- `n8n.xxx.com`
- `home.xxx.com`

홈 서버 매니아에게는 신이 내린 기능이다.

## 무료 Access

Access는 어드민 패널, 스테이징 환경, 내부 도구 앞에서 신원을 확인한 뒤 통과시킨다. 이메일 OTP, Google, GitHub, 팀 ID 공급자가 모두 동작한다 — 내부 페이지 하나 때문에 회원가입/로그인 시스템을 또 짤 필요가 없다. 예를 들어:

- 지정된 이메일만 들어옴
- Google 로그인만 들어옴
- GitHub 로그인만 들어옴
- 팀원만 들어옴

백엔드, 스테이징, 내부 도구를 보호하는 데 아주 유용하다.

## 무료 AI Gateway

AI Gateway는 여러 모델 제공업체 앞에 놓고 요청, 지연, 오류, 캐시 히트를 일괄 기록하며, 레이트 리밋과 폴백까지 처리한다. 초기 AI 제품을 만들 때, 여러 호환 API를 하나의 진입점으로 관리하면 수고를 크게 던다.

이런 걸 관찰할 수 있다:

- 요청량
- 지연 시간
- 오류
- 캐시 히트
- 모델 호출
- 레이트 리밋
- 폴백

OpenAI, Anthropic, Workers AI, 각종 호환 API를 쓰든, 앞에 한 겹을 감쌀 수 있다.

초기 AI 제품에는 훌륭한 통합 진입점이 된다.

## 무료 Browser Run

Cloudflare는 이제 이 기능을 Browser Run이라고 부른다. 클라우드에서 전체 브라우저 세션을 실행하며, 코드나 AI로 제어할 수 있다.

좋은 용도:

- 웹페이지 스크린샷
- 웹페이지를 Markdown으로
- 웹페이지 자동화 테스트
- 페이지 콘텐츠 스크래핑
- 동적 페이지 파싱
- 웹페이지를 PDF로

일별 무료 할당량이 있다.

## 무료 Images Transform

Cloudflare Images는 리사이즈, 크롭, 포맷 변환을 위한 트랜스폼 할당량을 제공한다. 사용량이 많으면 별도 과금되거나, 유료 Workers에서 Containers로 자체 트랜스코딩 서비스를 돌릴 수 있다.

R2와 함께 쓰면:

- R2가 원본을 저장
- Images가 썸네일과 포맷 변환
- Cloudflare 캐시가 분배

블로그 커버, 아바타, 제품 이미지, 기사 삽화에 좋다.

Cloudflare의 무료 할당량은 개인 프로젝트 상당수를 이미 커버한다. 더 높은 요청량, 컴퓨팅 시간, 유료 기능이 정말 필요하면 월 $5짜리 Workers Paid부터 시작해서 키워 나가자.
