اكتشفت شيئاً رائعاً: DeepSeek دمجت رسمياً البحث عبر الإنترنت في واجهة API.

## الشرح في سطر واحد

باستدعاء نموذج `deepseek-v4-flash` عبر واجهة **بصيغة Responses**، يكفي أن تُعلن عن أداة `web_search` في معاملات الطلب، لتحصل مباشرة على قدرة بحث ينفّذها خادم DeepSeek.

لا حاجة لربط محركات بحث خارجية بنفسك، ولا لتقديم طلبات مفاتيح بحث إضافية؛ كامل سير عمل البحث يحتضنه المصدر الرسمي.

## كيفية الاستخدام

التوثيق الرسمي: <https://api-docs.deepseek.com/zh-cn/guides/responses_api>

الجوهر هو إعلان الأداة:

```js
const response = await fetch('https://api.deepseek.com/responses', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': `Bearer ${process.env.DEEPSEEK_API_KEY}`
  },
  body: JSON.stringify({
    model: 'deepseek-v4-flash',
    tools: [{ type: 'web_search' }],
    input: '2026 年 8 月 AI 行业发生了什么大事？'
  })
})
```

وهذا كل شيء. ما تبقى — البحث والجلب والتحليل والاستشهاد — كله على عاتق خادم DeepSeek.

## لماذا هذا الأمر مهم

لكي يحصل الذكاء الاصطناعي على معلومات لحظية، كان عليك سابقاً أن تبني سلسلة بنفسك: اختر محرك بحث (مثل SerpAPI أو Bing Search) → قدّم طلب مفتاح API → اكتب كود الجلب والتحليل → احشُ نتائج البحث في السياق → وتراقب الميزانية أيضاً.

هذه العملية برمتها تستغرق يوماً أو يومين على أقل تقدير، وقد تمتد إلى أسبوع، وكل خطوة فيها تكلف مالاً: واجهة البحث تُحسب بالاستدعاء، والجلب يتطلب التعامل مع أنظمة مكافحة الزحف.

أما الآن فدمجتها DeepSeek مباشرة، وباستخدام نموذج `deepseek-v4-flash` الرخيص لدرجة مذهلة. البحث والتوليد في سلسلة واحدة، بتكلفة منخفضة يمكنك التعامل معها وكأنها ماء جارٍ.

## السيناريوهات المناسبة

- كتابة محتوى يتطلب حداثة المعلومات (أخبار الصناعة، مقارنات المنتجات، تحليلات السياسات)
- بناء وكلاء (Agent): في الخطوات التي تتطلب البحث ثم اتخاذ القرار
- أنظمة الدعم والإجابة: ابحث عن أحدث المعلومات قبل الرد
- أي سيناريو يعيقه "تاريخ قطع المعرفة" للنموذج

## ملاحظات

1. **استخدم واجهة Responses**، لا واجهة Chat Completions القديمة. فالواجهة القديمة لا تحتوي هذه الأداة.
2. تفاصيل دقة البحث وصيغ الاستشهاد موثقة في التوثيق الرسمي؛ جرّبه فعلياً لترى بنية الاستجابة.
3. توجد آلية خصم للتخزين المؤقت؛ في السيناريوهات ذات السياق الطويل استفد منها، فهي توفر كثيراً.

هذه مجانية حقيقية: الشركة تهديك البنية الأكثر إزعاجاً في البحث هدية. من يحتاجها فليأخذ الحل جاهزاً.
