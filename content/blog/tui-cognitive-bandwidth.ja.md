最近の AI Coding Agent は何かというと TUI を載せてくる。この風潮については、Claude Code が大きな責任を負うべきだ。ターミナルで AI と対話しながらコードを書くということを極限まで磨いたのは事実だが、同時に一つの美的感覚と経路依存も広めてしまった。まるで本当にハイレベルな Coding Agent はデフォルトでターミナル UI であるべきかのようで、Web 版はむしろ付属品、さらには「プログラマーらしくない」と嘲笑される始末。

結果どうなったか？まず複雑な TUI を作る。いろんな色、ステータスバー、ショートカットキー、モード切り替え。それでお約束のように「没入型」「高効率」「プログラマーへの敬意」と美称する。

本当に？

## 対話しているつもりが、実は格闘している

毎日ターミナルに浸っている一部の人にとって、TUI は確かに気持ちいい。でも、より多くの人にとっては人為的に作られたハードルだ。TUI で Agent と協業しているとき、あなたは実は常に三つのことをやらされている：

**ショートカットとモードを思い出す。**ツールごとにキーバインドの流儀が違い、新規ユーザーはポカーンとするし、古参ユーザーもツールを替えたら再適応が必要になる。

**スクロールする文字の流れの中で情報を探す。**状態は広げて見せられるのではなく、タイムラインに埋もれている。スクロールと検索で「発掘」するしかない。

**変な状態に誤爆していないことを祈る。**モード切り替えは目に見えない。問題が起きるまで、自分が今どのモードにいるのか分からないことがよくある。

もうインタラクションではない。インターフェースとの格闘だ。

## 情報密度は情報効率ではない

TUI の擁護者が一番好んで口にする言葉が「情報密度」だ。だが情報密度を極限まで積み上げた代償は、可読性と復元性が最低まで踏みにじられることになる。

本当に効率的なインターフェースは、**状態を広げて見せてくれる**ものだ。どのタスクが動いていて、どのセッションが入力待ちで、どのファイルが変更されたのか、一瞥すれば分かる。すべてを短期記憶に詰め込んで、頭の中で「現在のシステム状態」の見えない地図を維持し続けることではなく、目と空間感覚で理解させてくれるべきだ。

人間の作業記憶には 4〜7 個のスロットしかない。TUI のインタラクションモデルは、本質的に、一番貴重な認知リソースを「問題を考える」ことではなく「インターフェースの状態を覚える」ことに浪費させる。

## それが悪い癖まで育てている

さらに悪いことに、TUI エコシステムはひどく悪い価値判断を育てている：**あるツールのキーバインドを使いこなせるかどうかを、能力そのものとして扱うことだ。**

結果として、人は問題を考える代わりに、インターフェースへの適応に大量のエネルギーを注ぐ。プログラマーを測る物差しは「このショートカットを暗唱できるか」になってしまい、「問題をきれいに分解できるか」ではなくなった。

良いツールは思考のコストを下げるべきであって、思考のコストを「このインターフェースをどう操作するか」に転嫁すべきではない。

## Web UI は速くてクリーンにだってできる

Web は遅い、「ネイティブ」じゃないと言う人がいる。2026 年だぞ。その論拠はとっくに死んでいる。

Web UI は速くてクリーンにできる：PWA としてインストールすればデスクトップクライアントとほぼ変わらないし、更新はもっと楽——ユーザーが手動でアップグレードする必要はなく、リロードすれば最新版になる。長時間セッション、並列マルチタスク、タスク状態の可視化。これらはまさにブラウザ DOM の得意分野であって、文字ストリームの得意分野ではない。

私のメイン構成は OpenChamber みたいな Web インターフェース + OpenCode カーネルで、長期間ヘビーに使っているが、実に安定している。強いて難癖をつけるなら、Web 側のたまの小さなバグは長期使用にまったく影響しない。むしろ一部の TUI のモード切り替えには何度もやられた。

## ツールは人のためにある。「ギーク」の証明のためではない

Claude Code 自体は強い。それは間違いない。だが「TUI こそ正統」という美的感覚と経路依存を広めたのは確かで、後に続く模倣勢はさらにひどい——インタラクションデザインをするのすら面倒がって、「ターミナルに生えている」ことをそのままハイレベルの証明扱いする。

反人間的なインタラクションをハイレベルに包装するなんて、本当に滑稽な話だ。

ツールは人のためにある。判断基準は常にこうあるべきだ：**タスク完了までの総コストを下げてくれたか？**もしインターフェースとの格闘にエネルギーを奪われるなら、どんなに「ギーク」でもマイナスの資産だ。

次に Coding Agent を選ぶときは、まずこのフィルターを外してから選ぼう。
