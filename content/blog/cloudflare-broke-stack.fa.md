بهترین روش‌های توسعهٔ مستقل در ۲۰۲۶: **استک همه‌کارهٔ فقیرانهٔ Cloudflare**.

## مرور استک

| لایه | انتخاب | هزینه |
|------|------|------|
| کدنویسی | Codex | اشتراک |
| کنترل نسخه | GitHub | رایگان |
| پرداخت | Stripe | کارمزد به‌ازای هر تراکنش |
| فرانت‌اند | TanStack Start | رایگان |
| بک‌اند | Hono + Cloudflare Workers | سهمیهٔ رایگان |
| استقرار | Cloudflare Pages | رایگان |
| دیتابیس | Cloudflare D1 | سهمیهٔ رایگان |
| ذخیره‌سازی فایل | Cloudflare R2 | سهمیهٔ رایگان |
| کش / پیکربندی | Cloudflare KV | سهمیهٔ رایگان |

## چرا این ترکیب

### Codex: کدنویسی و انجام کل توسعهٔ فول‌استک

کدنویسی با هوش مصنوعی دیگر ابزار پیش‌فرض بهره‌وری توسعه‌دهندگان مستقل است. حالت Agent در Codex زنجیرهٔ «نیاز → کد → تست → استقرار» را تقریباً به هیچ می‌رساند — یک نفر کار یک تیم کامل را انجام می‌دهد.

### فرانت‌اند TanStack Start + بک‌اند Hono

TanStack Start یک فریم‌ورک فول‌استک React است که با اکوسیستم Workers هماهنگی خوبی دارد. برای بک‌اند هم Hono — فریم‌ورک کوچکی که برای Workers ساخته شده و در مسیریابی (routing)، میان‌افزار و راهنمای تایپ (type hints) راحت است. حجم کم، راه‌اندازی سریع.

### دیتابیس D1 + ذخیره‌سازی R2 + کش KV

این سه‌گانه، هستهٔ سهمیهٔ رایگان Cloudflare است:

- **D1**: دیتابیس رابطه‌ای سازگار با SQLite. سهمیهٔ رایگانش برای پروژه‌های شخصی بیش از اندازه کافی است.
- **R2**: ذخیره‌سازی اشیاء سازگار با S3. ده گیگابایت رایگان و هزینهٔ خروجی (egress) صفر — همین یک مورد AWS را کاملاً له می‌کند.
- **KV**: ذخیره‌سازی کلید-مقدار توزیع‌شدهٔ جهانی، عالی برای پیکربندی، کش و نشست‌ها.

### استقرار با Pages + زیرساخت کاملاً رایگان

Pages مستقیماً به مخزن گیت‌هاب وصل می‌شود — با هر push استقرار انجام می‌شود، با CDN و HTTPS خودکار. دامنه، DNS و CDN — همه یکجا در Cloudflare، و سهمیهٔ رایگان یک خط محصول کامل را روی پا نگه می‌دارد.

## ماهیت استراتژی فقیرانه

- **سهمیهٔ رایگان را حداکثری بچلان**: DNS، CDN، Pages، Workers، KV، D1، R2، Tunnel، AI Gateway — هر چیز رایگانی را راه بینداز.
- **جایی که می‌شود رایگان استفاده کرد، پول نده**: پول اشتراک فقط صرف جاهایی شود که واقعاً مهم‌اند (Codex)؛ بقیه روی زیرساخت رایگان.
- **یک پلتفرم برای همه‌چیز**: بین چند کلود بالا و پایین نپر، و کمترین فشار ذهنی برای نگهداری.

## مناسب چه کسانی

توسعه‌دهندگان مستقلی که بودجهٔ محدودی دارند و می‌خواهند سریع محصول‌شان را اعتبارسنجی کنند؛ علاقه‌مندان کدنویسی با هوش مصنوعی که نمی‌خواهند انرژی زیادی صرف زیرساخت کنند؛ و هر پروژه‌ای که می‌خواهد «اول راه بیفتد، بعد تکلیفش روشن شود».

Cloudflare بودیساتوای (bodhisattva) سایبری توسعه‌دهندگان مستقل است. بدون خرج کردن حتی یک ریال هم می‌توانی محصولی کاملاً در حال اجرا داشته باشی. جزئیات: [چطور یک کاربر رایگان می‌تواند Cloudflare را تا ته بچلاند](/blog/free-cloudflare).
