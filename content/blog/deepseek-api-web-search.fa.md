یک چیز عالی پیدا کردم: دیپ‌سیک واقعاً جستجوی وب را مستقیم داخل API خودش گذاشته.

## در یک جمله

مدل `deepseek-v4-flash` را از طریق رابط **Responses** صدا بزن. فقط کافی است ابزار `web_search` را در پارامترهای درخواست اعلام کنی تا قابلیت جستجو را در سمت سرور دیپ‌سیک داشته باشی.

نه یکپارچه‌سازی موتور جستجوی شخص ثالث، نه گرفتن کلید API جداگانه برای جستجو — کل زنجیرهٔ جستجو توسط دیپ‌سیک نگهداری می‌شود.

## روش استفاده

مستندات رسمی: <https://api-docs.deepseek.com/zh-cn/guides/responses_api>

مهم‌ترین بخش فقط اعلام کردن ابزار است:

```js
const response = await fetch('https://api.deepseek.com/responses', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': `Bearer ${process.env.DEEPSEEK_API_KEY}`
  },
  body: JSON.stringify({
    model: 'deepseek-v4-flash',
    tools: [{ type: 'web_search' }],
    input: 'در اوت ۲۰۲۶ چه اتفاقات مهمی در صنعت هوش مصنوعی افتاد؟'
  })
})
```

همین. جستجو کردن، گرفتن صفحه، تجزیه (parsing) و استناددهی — همه در سمت دیپ‌سیک انجام می‌شود.

## چرا این مهم است

قبلاً، برای اینکه به هوش مصنوعی اطلاعات به‌روز بدهی باید کل زنجیره را خودت می‌ساختی: یک موتور جستجو انتخاب کن (SerpAPI، Bing Search و…) → کلید API بگیر → کدِ دریافت و تجزیه بنویس → نتایج را داخل کانتکست بگذار → و چشم به بودجه هم داشته باشی.

این کار دست‌کم یکی دو روز وقت می‌برد و اگر گیر بکنی شاید یک هفته؛ و هر مرحله‌اش هزینه دارد: APIهای جستجو به‌ازای هر درخواست حساب می‌کنند و اسکرپ کردن هم یعنی جنگیدن با ضدربات‌ها.

حالا دیپ‌سیک همین قابلیت را داخل خودش گذاشته، آن هم با مدل فوق‌العاده ارزان `deepseek-v4-flash`. جستجو و تولید در یک زنجیره، آن‌قدر ارزان که مثل آب لوله‌کشی بشود از آن استفاده کرد.

## کاربردهای خوب

- نوشتن هر مطلبی که به زمان حساس است (اخبار صنعت، مقایسهٔ محصولات، توضیح سیاست‌ها)
- ساختن Agent: قدم‌هایی که قبل از تصمیم‌گیری باید چیزی را جستجو کنند
- سیستم‌های پشتیبانی مشتری / پرسش‌وپاسخ: قبل از پاسخ، آخرین اطلاعات را جستجو کن
- هر سناریویی که مرز دانش مدل (knowledge cutoff) جلویت را بگیرد

## نکته‌ها

1. **از رابط Responses استفاده کن**، نه رابط قدیمی Chat Completions. رابط قدیمی این ابزار را ندارد.
2. ریزدانه‌بودن جستجوی وب و قالب استنادها در مستندات رسمی است — ارزشش را دارد یک بار اجرا کنی و ساختار پاسخ را ببینی.
3. مکانیزم تخفیف کش (cache) وجود دارد — در سناریوهای کانتکست طولانی حتماً از آن استفاده کن، حسابی صرفه‌جویی می‌شود.

این یک سوغات واقعی است: تیم رسمی دردناک‌ترین بخش زیرساخت جستجو را رایگان داد. اگر نیازش داری، فقط همین تمرین را کپی کن.
