最近 Pi Agent、OMP、ZCode、Codex、OpenCode あたりの Agent Harness をあれこれ試して、ようやく自分が本当に求めているものが分かった。

## 私の三つの基準

### その一：成熟して安定した GUI

GUI に慣れてしまうと、TUI にはもう戻れない。黒い枠の中でチャットするのはしんどすぎる——たくさんのショートカットやコマンドを覚えないと使い続けられない。でも GUI なら、直感的にアイコンをポチポチして、ボタンを押すだけでいい。

だから成熟していて、安定していて、見た目も良い GUI が絶対条件。

この一本で **Pi Agent** と **OMP** は即アウト。カーネルがダメなわけじゃない。付属のコミュニティ GUI が出来が悪すぎる。自作しようとすると労力がバカにならないし、こういうツールはカスタマイズ性が高すぎて、自作 GUI に汎用性がない——マシンを変えれば、人を変えれば、全部やり直し。

### その二：ベンダーロックインなし、ベンダー贔屓なし

Codex は確かにサードパーティモデルの設定口を開放しているけど、設定が本当に面倒だし、サードパーティモデルは永遠に「二流市民」扱い——公式モデルに押さえつけられ、アップデートのタイミングに振り回される。これがとても不愉快。

ZCode はもっとアレで、OAuth で各社の Coding Plan（Kimi For Code とか Grok Build とか）にログインできない。邪道なハックをしない限り ZCode の中で使えない。

だから ZCode、Codex みたいなモデルベンダー贔屓のあるソフトは切った。

### その三：オープンソースで二次開発ができる

自分のニーズに合わせて二次開発やカスタマイズをして、顧客に「開けたらすぐ使える」状態を届けたい。だからオープンソースで、ライセンス的にフレンドリーなプロダクトが必須——自分が気持ちよく使えるし、顧客も簡単に使える。黒魔術でハックするみたいな真似はしたくない。

## 最終回答：OpenCode + OpenChamber

消していった末に、本当に選べるのは **OpenCode** だけだった。

でも OpenCode はあくまで Agent のカーネル。それに成熟・安定・使いやすい GUI を組み合わせる——ようやく見つけた真のバージョン回答が **OpenChamber** だ。

- カーネル：OpenCode、オープンソース、ロックインなし、各社モデル対応
- インターフェース：OpenChamber、しっかりした GUI ワークベンチ
- 組み合わせ：安定したカーネル + 使いやすい画面、必要に応じて二次開発も可能

ソースコード：<https://github.com/openchamber/openchamber>

## いくつか所感

ツール選びというのは、本質的に「誰に決定権を握らせるか」の選択だ。

クローズドなツールは、どう良くてもアップデートの方向性、モデル対応、価格戦略が他人の決め事で、こちらは受け身になるしかない。オープンソース + 非ロックインの組み合わせなら、いつでも逃げ道があるし、いつでも改造の自由がある。

TUI と GUI の争いについては、無理に我慢しない方がいい。ツールは仕事をするためのものだ。コマンドラインを使いこなせる証明のためじゃない。心地よい画面で長く使い続けられることが、何より大事。
