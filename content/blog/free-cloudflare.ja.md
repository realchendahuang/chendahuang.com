Cloudflare はほぼ個人用インターネット基盤一式を支えられる：ドメイン、サイト、CDN、オブジェクトストレージ、データベース、エッジ関数、内網トンネル、メール転送、認証、AI ゲートウェイまで、全部無料版から始められる。

## 無料 DNS

Cloudflare 自体がドメインレジストラでもあって、登録・更新の価格は割と透明。Spaceship みたいなプラットフォームでドメインを買ってから、DNS を Cloudflare に預ける手もある。

ドメインを Cloudflare に入れると、そのまま使い勝手のいい DNS 管理システムを手に入れられる。

ポイントは：問い合わせ件数で課金しないこと。国内の一部の大手はマジでウザくて、解析回数で課金しやがる？ ガメついにもほどがある。

Cloudflare はマルチドメイン、多数のサブドメイン、小プロジェクト群にぴったりだ。

こんなことができちゃう：

- `api.xxx.com`
- `img.xxx.com`
- `cdn.xxx.com`
- `docs.xxx.com`
- `status.xxx.com`
- `admin.xxx.com`

ドメインを一つ買えば、サービスごとに別々のサブドメインを割り当てられる。DNS 解析そのものに追加費用はかからない。

プロキシが必要な Web トラフィックはオレンジ雲を ON にして、Cloudflare にプロキシ、キャッシュ、HTTPS 証明書を任せられる。

## 無料 CDN

CDN キャッシュは Cloudflare の最強機能。多くの人がこれで Cloudflare を知る。ブログ、公式サイト、ドキュメントサイトにとって最も直接的な価値は：

アクセスが少し速く、オリジンが少し軽く、帯域が少し節約できる。特に安い VPS を使っているなら、前に Cloudflare を置くと体験がかなり良くなる。

## 無料 Pages

Pages は静的サイトやフロントエンドプロジェクトを無料でホスティングできる。

- 個人ブログ
- 製品公式サイト
- ドキュメントサイト
- ランディングページ
- オープンソースプロジェクトのホーム
- コース資料ページ
- ウェイティングリストページ
- ダウンロード説明ページ
- 電子書籍宣伝ページ

こうしたページはそのままホスティングできて、わざわざサーバーを買う必要がない。自分のドメインを紐付けすれば、長期運用の個人サイトやプロジェクトページになる。

## 無料 Workers

サイトに API、認証、その他の動的ロジックが必要なら Workers が使える。コードは Cloudflare のネットワーク上で動き、自分でサーバーを管理する必要なし。JavaScript / TypeScript の他、WebAssembly などでの実行にも対応。

無料版は毎日 10 万リクエスト分の枠がある。個人プロジェクトが本当に安定してこの量を超えたら、その時に有料版にすればいい。

Workers Paid の開始価格は月 5 ドル。

多くの小プロジェクトにはフルバックエンドがそもそも不要。Worker 一つで十分。

## 無料 KV

KV は高速読み出しが必要で、強い一貫性は要らないデータ、例えば設定、機能フラグ、キャッシュ結果に最適。完全な Redis の代替ではないけど、個人プロジェクトの簡単なニーズの多くはこれで足りる。

## 無料 D1

D1 は Cloudflare がホストする SQLite データベースで、リレーショナルデータ向き。無料版は合計 5 GB のストレージ枠で、読み書きそれぞれに日次枠がある。

## 無料 R2

R2 は S3 API 互換のオブジェクトストレージで、画像、添付ファイル、バックアップ向き。最大の利点は R2 からの出口トラフィックに帯域課金がないことで、費用は主にストレージ量と操作回数で決まる。無料版にもストレージとリクエストの枠がある。

こんなものを置ける：

- 画像
- 添付ファイル
- PDF
- コース資料
- ソフトウェアパッケージ
- バックアップファイル
- ユーザーアバター
- Markdown の画像
- 静的リソース
- データセット
- 音声ファイル
- 小さい動画素材

## 無料 Email Routing

Email Routing はカスタムドメイン宛のメールを既存のメールボックスに転送できて、無料版で使える。Cloudflare は今、Workers 経由でトランザクションメールを送る Email Sending もあるけど、任意の受信者への送信には Workers Paid が必要で、無料の受信転送と混同しないように。

## 無料 Turnstile

Turnstile は Cloudflare の人 vs ボット認証で、普通はユーザーに信号機や歪んだ文字を認識させない。置くのに向いている場所：

- ログイン
- 登録
- コメント
- お問い合わせフォーム
- ウェイティングリスト
- ダウンロードページ
- メール購読

## 無料 Tunnel

家の NAS、ローカル開発機、ゲームサーバーを外からアクセスさせたいなら、Tunnel で内網から Cloudflare へ主動接続するトンネルを張れる。

家の NAS、ローカル開発機、内網サービスを Cloudflare Tunnel で露出できる。核心的な価値：

- パブリック IP 不要
- ルーターのポート開放不要
- オリジン IP を晒さない
- 自分のドメインを付けられる

例えば：

- `nas.xxx.com`
- `dev.xxx.com`
- `panel.xxx.com`
- `n8n.xxx.com`
- `home.xxx.com`

これは家庭サーバー派には最高すぎる。

## 無料 Access

Access はバックエンド、テスト環境、社内ツールの前に置いて、ID 確認が通ってから通す。メールワンタイムコード、Google、GitHub、チーム ID プロバイダまで接続できて、社内ページのためだけにまた登録・ログインを書く必要がない。例えば：

- 指定メールアドレスだけ入れる
- Google ログインだけ入れる
- GitHub ログインだけ入れる
- チームメンバーだけ入れる

バックエンド、テスト環境、社内ツールを守るのに非常に使える。

## 無料 AI Gateway

AI Gateway は複数のモデルベンダーの前に置けて、リクエスト、レイテンシ、エラー、キャッシュヒットを一元的に記録し、レート制限や fallback もできる。AI プロダクトを初期に作るとき、一つの入り口で複数の互換 API を管理するのはだいぶ楽になる。

これで見られるもの：

- リクエスト量
- レイテンシ
- エラー
- キャッシュヒット
- モデル呼び出し
- レート制限
- fallback

OpenAI、Anthropic、Workers AI、各種互換 API に繋いでいても、前に一枚挟める。

AI プロダクトの初期には、統一入り口として使うのにぴったり。

## 無料 Browser Run

Cloudflare は今この機能を Browser Run と呼んでいる。クラウド上で完全なブラウザセッションを起動し、コードや AI でページを操作できる。

向いている用途：

- ウェブページのスクリーンショット
- ウェブページの Markdown 変換
- ウェブページの自動化テスト
- ページ内容の収集
- 動的ページの解析
- ウェブページの PDF 変換

毎日無料枠がある。

## 無料 Images Transform

Cloudflare Images に画像変換の枠があって、リサイズ、クロップ、形式変換ができる。大量に使うなら別途かかるし、有料 Workers で Container を動かして自分でトランスコードサービスを回す手もある。

これは R2 と組み合わせて遊べる：

- R2 に原画像
- Images でサムネイルと形式変換
- Cloudflare キャッシュで配信

ブログの表紙、アバター、商品画像、記事のイラストにぴったり。

Cloudflare の無料枠はすでに結構な個人プロジェクトをカバーできる。本当に大量のリクエスト量、計算時間、有料機能が必要になったら、月 5 ドルの Workers Paid から上に足していけばいい。
