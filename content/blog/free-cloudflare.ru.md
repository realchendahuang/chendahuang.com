Cloudflare может тянуть почти всю персональную интернет-инфраструктуру: домены, сайты, CDN, объектное хранилище, базы данных, edge-функции, туннелирование, переадресацию почты, CAPTCHA и AI-шлюз — всё это можно поднять на бесплатном тарифе.

## Бесплатный DNS

Cloudflare — сам по себе регистратор доменов, с достаточно прозрачными ценами на регистрацию и продление. Также можно покупать домены на площадках вроде Spaceship и переводить DNS-хостинг на Cloudflare.

Как только домен попал на Cloudflare, ты получаешь нормальную систему управления DNS.

Ключевой момент: разрешение DNS не тарифицируется за запрос. В отличие от некоторых крупных отечественных провайдеров, которые дошли до наглости брать деньги за число запросов резолвинга — вот это уже бесстыдство.

Cloudflare отлично подходит для матрицы из множества доменов, поддоменов и мелких проектов.

Можно развести:

- `api.xxx.com`
- `img.xxx.com`
- `cdn.xxx.com`
- `docs.xxx.com`
- `status.xxx.com`
- `admin.xxx.com`

Купил один домен, раздал разные поддомены разным сервисам — само разрешение DNS больше ничего не стоит.

Для веб-трафика, которому нужен прокси, включай «оранжевое облачко» — и пусть Cloudflare занимается проксированием, кэшированием и HTTPS-сертификатами.

## Бесплатный CDN

CDN-кэширование — самая классная штука у Cloudflare, именно с неё большинство людей впервые узнают о компании. Для блогов, официальных сайтов и документации ценность очевидна:

Посетители грузятся быстрее, origin-сервер разгружен, трафика меньше. Особенно заметно, если сидишь на дешёвом VPS — Cloudflare спереди дают ощутимую разницу.

## Бесплатный Pages

Pages может бесплатно хостить статические сайты и фронтенд-проекты.

- Личные блоги
- Сайты продуктов
- Сайты документации
- Лендинги
- Страницы open-source проектов
- Страницы учебных материалов
- Страницы листов ожидания
- Страницы с инструкциями по скачиванию
- Страницы продвижения электронных книг

Всё это можно хостить напрямую, без покупки отдельного сервера. Привязываешь свой домен — и получаешь долгосрочный личный сайт или домашнюю страницу проекта.

## Бесплатный Workers

Когда сайту нужны API, авторизация или другая динамическая логика — бери Workers. Код крутится в сети Cloudflare, обслуживать сервер самому не надо. Кроме JavaScript/TypeScript, поддерживаются WebAssembly и другие рантаймы.

Бесплатный тариф включает 100 000 запросов в день. Если личный проект реально перерастает этот лимит — переходи на платный, торопиться некуда.

Workers Paid начинается от $5 в месяц.

Многим мелким проектам полноценный бэкенд вообще не нужен. Одного Workers хватает.

## Бесплатный KV

KV подходит под данные, которые нужно быстро читать, но не требуется строгая согласованность: конфиги, фиче-флаги, закэшированные результаты. Это не полноценная замена Redis, но в личных проектах закрывает кучу простых потребностей.

## Бесплатный D1

D1 — управляемая SQLite-база данных от Cloudflare, хорошо подходит для реляционных данных. Бесплатный тариф включает 5 ГБ суммарного хранилища плюс ежедневные квоты на чтение и запись.

## Бесплатный R2

R2 — объектное хранилище с API, совместимым с S3; хорошо для картинок, вложений и бэкапов. Главное преимущество: при отдаче из R2 нет платы за трафик — платишь в основном за хранение и операции. Есть и бесплатный тариф с квотами на то и другое.

Можно складывать туда:

- Картинки
- Вложения
- PDF
- Учебные материалы
- Пакеты ПО
- Файлы бэкапов
- Аватары пользователей
- Картинки для Markdown
- Статические ассеты
- Датасеты
- Аудиофайлы
- Небольшие видеоматериалы

## Бесплатный Email Routing

Email Routing переадресует письма, отправленные на ваш кастомный домен, в существующий ящик — доступен на бесплатном тарифе. У Cloudflare есть и Email Sending для транзакционной почты через Workers, но рассылка произвольным получателям требует Workers Paid, так что не путайте это с бесплатной входящей переадресацией.

## Бесплатный Turnstile

Turnstile — человеческая верификация от Cloudflare, и пользователям обычно даже не приходится искать на картинке светофоры или разбирать искажённые буквы. Годится для:

- Логина
- Регистрации
- Комментариев
- Контактных форм
- Листов ожидания
- Страниц скачиваний
- Почтовых подписок

## Бесплатный Tunnel

Хочешь выставить свой домашний NAS, локальную dev-машину или игровой сервер в интернет? Tunnel строит трубу из твоей внутренней сети наружу, в сторону Cloudflare, по активному соединению.

NAS, локальные dev-боксы, внутренние сервисы — всё можно открыть наружу через Cloudflare Tunnel. Ключевая ценность:

- Не нужен публичный IP
- Не нужен проброс портов на роутере
- Не светятся origin-IP
- Можно привязать свой домен

Например:

- `nas.xxx.com`
- `dev.xxx.com`
- `panel.xxx.com`
- `n8n.xxx.com`
- `home.xxx.com`

Эта штука — подарок судьбы для тех, кто возится с домашними серверами.

## Бесплатный Access

Access встаёт перед админками, стейджинг-окружениями и внутренними инструментами и проверяет личность перед входом. Работают email-OTP, Google, GitHub или корпоративные IdP — не нужно писать ещё одну систему регистрации/логина ради одной внутренней страницы. Например:

- Пускать только с определённых email
- Пускать только через Google-логин
- Пускать только через GitHub-логин
- Пускать только членов команды

Это очень удобно для защиты бэкенда, стейджинга и внутренних инструментов.

## Бесплатный AI Gateway

AI Gateway может встать перед несколькими провайдерами моделей, единообразно логируя запросы, задержки, ошибки и попадания в кэш, плюс рейт-лимитинг и фолбэк. На раннем этапе построения ИИ-продукта управлять множеством совместимых API через одну точку входа — большая экономия нервов.

Он позволяет наблюдать:

- Объём запросов
- Задержки
- Ошибки
- Попадания в кэш
- Вызовы моделей
- Рейт-лимитинг
- Фолбэк

Будь то OpenAI, Anthropic, Workers AI или прочие совместимые API — перед ними можно обернуть один слой.

Для ранних ИИ-продуктов это отличная единая точка входа.

## Бесплатный Browser Run

Теперь Cloudflare называет это Browser Run. Он поднимает полноценные браузерные сессии в облаке, управляемые кодом или ИИ.

Годится для:

- Скриншотов страниц
- Конвертации страницы в Markdown
- Автоматизированного тестирования страниц
- Скрейпинга контента страниц
- Парсинга динамических страниц
- Конвертации страницы в PDF

Есть ежедневная бесплатная квота.

## Бесплатный Images Transform

У Cloudflare Images есть квота на трансформации: изменение размера, кадрирование, конвертация форматов. Интенсивное использование оплачивается отдельно, либо можно запустить свой транскодинг-сервис на платных Workers с Containers.

В паре с R2:

- R2 хранит оригиналы
- Images делает превью и конвертацию форматов
- Кэш Cloudflare раздаёт по сети

Хорошо для обложек блога, аватарок, картинок продуктов и иллюстраций к статьям.

Бесплатной квоты Cloudflare уже хватает на кучу личных проектов. Если реально нужен больший объём запросов, вычислительное время или платные фичи — апгрейдись с уровня Workers Paid за $5 в месяц и масштабируйся.
